# نواة | Nawah 🌴

موقع ويب يتعرف على نوع التمرة من صورتها ويعرض سعراتها وسكرها، مع قائمة شركات التمور.

## التشغيل

```
pip install -r requirements.txt
set ANTHROPIC_API_KEY=sk-ant-xxxxxxxx      (مفتاح الذكاء الاصطناعي الحقيقي)
set ADMIN_PASSWORD=nawah2026               (كلمة مرور لوحة الإدارة تختارينها)
py -m uvicorn main:app --reload
```

(في ماك أو لينكس استخدمي `export` بدل `set`، و`python3` بدل `py`.)

ثم افتحي: http://localhost:8000  (لوحة الإدارة: /admin)

## قاعدة البيانات (SQL) وفتحها من Anaconda

قاعدة البيانات ملف واحد اسمه `nawah.db` (SQL من نوع SQLite)، وفيه 4 جداول.

**لعرضها وتعديلها من Anaconda:**
1. افتحي Anaconda Navigator ثم Jupyter Notebook.
2. ادخلي مجلد `nawah` وافتحي `view_database.ipynb`.
3. شغّلي الخلايا بالترتيب. فيه أمثلة لعرض الجداول وتعديل التقييمات وإضافة الشركات وتصدير Excel.

**ملف `nawah_database.sql`:** نفس القاعدة بصيغة أوامر SQL نصية (إنشاء الجداول والبيانات). يصلح للتسليم أو لإعادة بناء القاعدة:
```
sqlite3 nawah.db < nawah_database.sql
```

## هيكل المشروع

| الملف | وظيفته |
|---|---|
| `database.py` | الاتصال بقاعدة البيانات |
| `models.py` | الجداول الأربعة: Variety, Company, Suggestion, Analysis |
| `seed.py` | البيانات الأولية (أنواع التمور والشركات) |
| `ai.py` | إرسال الصورة للذكاء الاصطناعي واستلام النوع |
| `main.py` | كل مسارات الـ API ولوحة الإدارة |
| `static/index.html` | الواجهة الرئيسية (الكاميرا + الشركات) |
| `static/admin.html` | لوحة الإدارة |
| `nawah.db` | قاعدة البيانات |
| `view_database.ipynb` | دفتر Jupyter لفتح القاعدة من Anaconda |
| `nawah_database.sql` | القاعدة بصيغة SQL نصية |

## مسارات الـ API

- `POST /api/analyze` تحليل صورة
- `POST /api/analyses/{aid}/feedback` رأي المستخدم
- `GET /api/varieties`, `GET /api/companies`
- `POST /api/suggest` اقتراح شركة
- `GET /api/stats`, `GET /api/dataset`
- `/api/admin/...` محمية بكلمة المرور

## ملاحظات مهمة

- **الذكاء الاصطناعي يختار فقط من الأنواع الموجودة في جدول Variety**، فلا يعطي نوعاً غير موجود؛ وإذا لم يتأكد يقول "لم نستطع تحديد النوع". لكنه قد يخطئ بين نوعين متشابهين، فجرّبي بصور حقيقية.
- القيم الغذائية في `seed.py` **تقريبية** وتحتاج مراجعة من مصدر علمي قبل التسليم.
- **الشركات في `seed.py` حقيقية** (الفوعة وباتيل ومصانع تعبئة سعودية)، ومصادرها مكتوبة أعلى القائمة في `seed.py`. التقييم والأنواع والهاتف فارغة لأننا لم نجد لها مصدراً موثوقاً، فأضيفيها من `view_database.ipynb` إذا توفرت لك.
- لم نجد شركات موثقة للبحرين والأردن وليبيا، فلا تظهر أزرارها حتى تُضاف شركة من تلك الدول.
- لتغيير الشركات الظاهرة: عدّلي جدول `companies` من `view_database.ipynb`، أو احذفي `nawah.db` وعدّلي القائمة في `seed.py` ثم شغّلي الموقع من جديد.
