# نواة | Nawah 🌴

موقع ويب يتعرف على نوع التمرة من صورتها ويعرض سعراتها وسكرها.

## التشغيل

```
pip install -r requirements.txt
set DEMO_MODE=1                            (تجربة بدون مفتاح: نتيجة عشوائية مكتوب عليها «تجريبية»)
set ANTHROPIC_API_KEY=sk-ant-xxxxxxxx      (بدلها للتحليل الحقيقي)
py -m uvicorn main:app --reload
```

(في ماك أو لينكس استخدمي `export` بدل `set`، و`python3` بدل `py`.)

ثم افتحي: http://localhost:8000

## قاعدة البيانات (SQL) وفتحها من Anaconda

قاعدة البيانات ملف واحد اسمه `nawah.db` (SQL من نوع SQLite)، وفيه جدولان: `varieties` (أنواع التمور) و`analyses` (سجل التحاليل).

**لعرضها وتعديلها من Anaconda:**
1. افتحي Anaconda Navigator ثم Jupyter Notebook.
2. ادخلي مجلد `nawah` وافتحي `view_database.ipynb`.
3. شغّلي الخلايا بالترتيب. فيه أمثلة لعرض الجداول وتعديل الأنواع وإضافة نوع جديد وتصدير Excel.

**ملف `nawah_database.sql`:** نفس القاعدة بصيغة أوامر SQL نصية (إنشاء الجداول والبيانات). يصلح للتسليم أو لإعادة بناء القاعدة:
```
sqlite3 nawah.db < nawah_database.sql
```

## هيكل المشروع

| الملف | وظيفته |
|---|---|
| `database.py` | الاتصال بقاعدة البيانات |
| `models.py` | الجدولان: Variety, Analysis |
| `seed.py` | البيانات الأولية (أنواع التمور وقيمها الغذائية) |
| `ai.py` | إرسال الصورة للذكاء الاصطناعي واستلام النوع |
| `main.py` | كل مسارات الـ API |
| `static/index.html` | الواجهة الرئيسية (الكاميرا + النتيجة) |
| `nawah.db` | قاعدة البيانات |
| `view_database.ipynb` | دفتر Jupyter لفتح القاعدة من Anaconda |
| `nawah_database.sql` | القاعدة بصيغة SQL نصية |

## مسارات الـ API

- `POST /api/analyze` تحليل صورة
- `POST /api/analyses/{aid}/feedback` رأي المستخدم
- `GET /api/varieties`
- `GET /api/stats`, `GET /api/dataset`

## ملاحظات مهمة

- **الذكاء الاصطناعي يختار فقط من الأنواع الموجودة في جدول Variety**، فلا يعطي نوعاً غير موجود؛ وإذا لم يتأكد يقول "لم نستطع تحديد النوع". لكنه قد يخطئ بين نوعين متشابهين، فجرّبي بصور حقيقية.
- القيم الغذائية في `seed.py` **تقريبية** وتحتاج مراجعة من مصدر علمي قبل التسليم.
- **النشر على Vercel:** الكتابة مسموحة في `/tmp` فقط، فتُعاد قاعدة البيانات والصور المرفوعة عند كل إعادة تشغيل للخادم (مناسب للعرض الجامعي). الحد الأقصى للطلب 4.5MB، والواجهة تصغّر الصورة قبل الإرسال.
- **وضع التجربة `DEMO_MODE=1`:** يعيد نوعاً عشوائياً من القاعدة مع علامة «نتيجة تجريبية» ظاهرة للمستخدم، ويُستعمل فقط عند غياب مفتاح الذكاء الاصطناعي.
